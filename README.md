# DepShield

## Open Source Dependency and Security Dashboard

DepShield is a web dashboard that helps users check software dependencies and find security problems.

## Features

- Dashboard overview
- Dependency management
- Vulnerability detection
- Security reports
- Severity filters (Critical, High, Medium, Low)
- Security summaries
- Settings and Help Center

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Lucide React
- Vite

## How to Run the Project

1. Install Node.js.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local link shown in the terminal.

## Purpose

The purpose of DepShield is to make software dependency security easier to understand and manage.
